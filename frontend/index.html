This LED is not an image or animation — it's being driven live by an actual AVR CPU emulator (avr8js) executing a real compiled .hex file, the same kind Arduino IDE produces. The C code below was compiled with avr-gcc, the exact compiler Arduino uses under the hood:

#define F_CPU 16000000UL #include <avr/io.h> #include <util/delay.h> int main(void) { DDRB |= (1 << PB5); // pin 13 = onboard LED while (1) { PORTB ^= (1 << PB5); // toggle LED _delay_ms(1000); } }
